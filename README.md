**אתר חי:** https://amirsportdiet.com (GitHub Pages + דומיין מ-Wix)

## איך מוסיפים מאמר לבלוג (בלי קוד)

1. נכנסים ל-`blog/posts/` ← **Add file** ← **Create new file**
2. שם באנגלית עם מקפים, למשל `protein-timing.md`, וכותבים את המאמר
   (פורמט פשוט - יש דוגמאות ב-`blog/posts/_TEMPLATE.md`)
3. **Commit changes**
4. עורכים את `blog/posts.js` ומוסיפים בלוק בראש הרשימה (יש שם הסבר מלא בעברית)
5. **Commit** - תוך דקה המאמר באוויר

## איך עובדים הלידים

טופס באתר ← Cloud Function בשם `submitLead` (פרויקט Firebase `wellnessprojectar`,
מוגבל לפניות מהדומיין בלבד) ← נכתב ל-`dashboard_leads` ← מופיע בדשבורד של אמיר
+ התראת פוש לטלפון. כל ליד כולל את העמוד שממנו נשלח.

## עדכון האתר

כל push ל-branch `master` עולה לאוויר אוטומטית תוך כדקה (GitHub Pages).

## הערות

- **מקפים:** באתר משתמשים במקף קצר (-), לא במקף ארוך (—)
- **סקשן ההמלצות** בעמוד הבית מוסתר (`display:none`) - להפעיל כשיש ציטוטים אמיתיים
- תמונת השיתוף `images/og.png` נוצרת מסקריפט PowerShell (אצל קלוד בזיכרון)
